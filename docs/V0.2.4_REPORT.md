# PROTOCOL ZERO V0.2.4 — joint framing and unknown CRC-8

Base: `dbdd7b813a94668c14acadf13697aa6f43d23732` on `research/v023-crc-discovery`. Existing APIs remain unchanged; new opt-in `protocol_zero.joint_crc` searches raw streams. Bounded family: top six observed two-byte syncs, 1/2-byte length at offsets 2..5, both byte orders for width two, 0..2 extra header bytes, payload <=512 bytes, non-reflected CRC-8 with any odd polynomial, CRC placed at the final or penultimate byte, CRC coverage starts at byte 0 or 2. A following byte is not protected; preserve equivalent protected spans despite different total coverage.

## Algorithm
For each layout, scan candidate frames. Repeated-length anchor (>=4 distinct bodies) obtains residual votes by removing the zero-init CRC. Search 128 odd polynomials and 256 initial states with XOR-out determined by the anchor. Require >=65% support in the anchor and overall distinct codewords, then independent validation, nonoverlap selection, >=35% coverage, and >=8 distinct train / >=6 novel validation bodies. When insufficient repeated lengths, use exact GF(2) elimination of the XOR-out and solve eight initial-state variables. This fallback is not robust to corrupted candidate words. Group behavior-equivalent parameter sets, keep near-top protected-boundary groups and all models sharing these protected spans. Only output unanimous frame spans as agreed; contested spans are hypotheses. The score window is heuristic. Training plus validation limited to 64 KiB and 4096 passing layout/behavior groups; not a hard wall-clock bound.

## Validation and evidence
44 current and 7 legacy tests passed locally; compilation and CLI smoke passed (30 agreed spans). Exact GF(2) solver compared to V0.2.3 exact parameter search on four seeds. Pilot on seeds 82400..82407 exposed missing distinct-length support and unjustified preference for an unchecked suffix; both fixed before final holdout.

Final held-out synthetic experiment: seeds 82500..82511, nine scenarios, 108 trials; 36 train / 24 validation / 30 test generated frames per trial, independent polynomial long-division generator. Baseline is V0.2.2 preset-only consensus with same sync limit (checksum memoization). Final F1 1.0 versus 0 for unknown CRC, bit noise, wide length, unique lengths, fixed length and sync decoys (12 runs each); known preset F1 1.0 for both. All 96 supported cases retain ground-truth layout and parameter tuple. Suffix ambiguity: agreed F1 0, possible-span recall 1.0 (12/12), not an identification success. Nonlinear checksums rejected 12/12. No false agreed spans observed. F1 is over exact spans of uncorrupted test frames, not damage reconstruction. Script records timings; no general speedup claim.

Exploratory stress seeds 82600..82611: 60/40/50 frames in train/validation/test. Random clean lengths: 12/12 accepted, F1 1.0; sparse random lengths with periodic bit noise: 7/12 accepted, overall mean F1 0.5833; deletion bursts with repeated lengths: 12/12 accepted, F1 1.0. Zero false agreed spans across these 36 trials. Five rejections highlight insufficient redundant equal-length observations plus corruption in the exact fallback. These are synthetic results, not real-device validation or proof of absence of error.

## Reproduce
`python -m unittest discover -s tests -v`; `python experiments/joint_crc_benchmark.py`; `python experiments/joint_crc_stress.py`. Both scripts regenerate detailed CSV. CLI: `python -m protocol_zero.joint_crc --train train.bin --validation val.bin --test test.bin --out result.json`. Python 3.10+ standard library only.

## Limits / next work
No real captures, hardware or remote CI, reflected CRC/CRC-16, unknown multi-byte sync, arbitrary coverage, multiple message families, or damage recovery in joint inference. CRC-8 success is not integrity proof. The constant sync prefix can be absorbed into an alternative initial state, so CRC coverage is often not identifiable. The bounded heuristic can miss the true model, especially with rare repeated-length groups and corruption. Next: robust GF(2) consensus estimation across different lengths, explicit search budget, out-of-family/noise stress and calibration; do not promote candidate repairs to verified frames.
