# PROTOCOL ZERO V0.9
Python 3.10+, standard library. Run `python evaluate_fields.py` to reproduce 80 synthetic streams (8000 frames). Earlier modules retained. CRC generator uses independent polynomial division; framing uses V0.8 CRC detector. Training/validation/test split 60/20/20 frames. Field inference uses training only; labels scored against simulator schema, framing checked on held-out frames. Baseline assumes a one-byte counter and otherwise knows the layout (not a third-party baseline). Unknown spans are not semantic labels. Terminal checksum assumed after CRC framing. Counter width is not identifiable without variation of high bytes; current implementation incorrectly commits to short counter or merges a constant byte. No real data or external tools tested. No claims of novelty.

## V0.10
`python evaluate_v10.py` runs 600 synthetic counter traces (300 observations each). `python -m unittest test_ambiguity` runs three unit tests. New module assumes known field offset and consecutive unit increments. It retains all compatible candidate widths 1/2/4 and endian orders. A little-endian counter's low byte remains a valid modulo-256 counter even after carry; uniqueness requires additional structural assumptions. This is a standalone field module, not integrated into end-to-end framing. Baseline chooses smallest compatible candidate on first 30 observations. No external tool comparison or real data.

## V0.11: carry dependency ranking
Run `python evaluate_v11.py` and `python -m unittest discover -v`.
900 synthetic cases, 40 observations each, 9 scenarios with 100 seeds each.
For the 700 single-counter cases in the supported family, shortest-candidate top-1 is 300/700; carry ranking is 500/700. All competing candidates remain visible. The coupled-byte control is observationally equivalent to a 16-bit counter; its logical field partition is not identifiable. The step-3 control is outside the model and all cases are rejected. Known start, exact unit steps, synthetic data only. No external baseline or real capture. Scores are observed carry counts, not probabilities. Existing pipeline retained, new module not integrated end-to-end.
