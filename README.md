# PROTOCOL ZERO V0.2.2

Research prototype: finite-observation equivalence, conservative frame consensus and length-only acquisition planning. Python 3.10+, standard library. The original V0.2.1 pipeline and tests remain available.

```bash
python -m unittest discover -s tests -v
python experiments/equivalence_benchmark.py
python -m protocol_zero.equivalence --train train.bin --validation validation.bin --test test.bin --allowed-frame-sizes 21 45 261 278 --out result.json
```

Optional `--complete-frames frame1.bin frame2.bin frame3.bin` requires independently delimited clean observations. No device commands and no automatic repairs. See [V0.2.2 report](docs/V0.2.2_REPORT.md) and [compact trial data](experiments/v022_trials_compact.csv). Raw result JSON and CSV are regenerated by the benchmark. Synthetic validation only. Previous V0.11 remains on `main`.
