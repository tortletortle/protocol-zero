# PROTOCOL ZERO

Research prototype: finite-observation equivalence, conservative frame consensus and length-only acquisition planning. Python 3.10+, standard library. The original V0.2.1 pipeline and tests remain available.

```bash
python -m unittest discover -s tests -v
python experiments/equivalence_benchmark.py
python -m protocol_zero.equivalence --train train.bin --validation validation.bin --test test.bin --allowed-frame-sizes 21 45 261 278 --out result.json
```

Optional `--complete-frames frame1.bin frame2.bin frame3.bin` requires independently delimited clean observations. No device commands and no automatic repairs. See [V0.2.2 report](docs/V0.2.2_REPORT.md) and [compact trial data](experiments/v022_trials_compact.csv). Raw result JSON and CSV are regenerated by the benchmark. Synthetic validation only. Previous V0.11 remains on `main`.

## V0.2.3 — unknown CRC-8 discovery

One independently delimited clean codeword per training/validation file; the final byte is assumed to be the CRC. Offline analysis only.

```bash
python -m protocol_zero.crc_discovery --train train*.bin --validation val*.bin --prospective probe.bin --observations obs.bin --out result.json
python experiments/crc_benchmark.py
python experiments/crc_exploratory.py
```

See [V0.2.3 report](docs/V0.2.3_REPORT.md). V0.2.2 streaming pipeline remains unchanged.

## V0.2.6 — CRC collision limits and integrity evidence

The V0.2.5 CRC consensus result is a candidate, not integrity proof. V0.2.6 adds a constructive same-bytes/different-histories collision witness and an audit wrapper that never promotes CRC/model agreement to integrity_verified.

    python -m unittest discover -s tests -v
    python experiments/integrity_collision.py --trials 50000 --seed 82607

See docs/V0.2.6_REPORT.md. The 1/256 baseline applies only to one uniformly random independent candidate byte and one fixed CRC-8 model; it is not a calibrated false-acceptance rate for model search or real traffic. No real-device validation or automatic repair.
